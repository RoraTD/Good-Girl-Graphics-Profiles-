How to install

  1. Sign in to your Utherverse account and open the profile editor.
  2. Open About Me. Remove the old profile code there, then paste the complete code below.
  3. Save the profile and refresh your profile page to check the result.

Before installing: Make a backup of any code you want to keep. The Clothing, Mail and Send Funds links are already included in the code. No editing of the code is needed.
