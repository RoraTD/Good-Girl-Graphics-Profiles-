How to install

  1. Sign in to your Utherverse account and open the profile editor.
  2. Open Books. Back up any old code there, then paste the complete code below.
  3. Save the profile and refresh your profile page to check the result.

Before installing: Make a backup of any code you want to keep. The Clothing, Mail and Send Funds links are already included in the code. No editing of the code is needed.

Personalize “Welcome to My World”

You can change your introduction without changing the profile design. Follow these steps before copying the code into Books:

  1. Click Download Complete Code below and open the downloaded .txt file in Notepad or another plain-text editor.
  2. Press Ctrl+F and search for <div class="azra-scroll-text">.
  3. Immediately below that line, you will find four paragraphs beginning with <p> and ending with </p>. Replace only the words between those tags with your own introduction.
  4. Leave the surrounding HTML, CSS, <p> tags, and closing </div> tags unchanged. To add a paragraph, use <p>Your new paragraph here.</p>.
  5. Save the edited file, copy its entire contents, and paste it into the Books section of your Utherverse profile. Save and refresh your profile.

Important: The Copy Complete Code button below copies the original version, not your edited file. If you personalize the text, copy the complete code from your saved .txt file instead.
